## Style Guidelines:

- Primary color: Forest green (#4CAF50) for a natural, calm feel.
- Background color: Very light green (#F1F8E9) provides a subtle contrast.
- Accent color: Earthy brown (#795548) for a touch of warmth.
- Body and headline font: 'PT Sans' (sans-serif) for readability.
- Center the text vertically and horizontally on the screen.
